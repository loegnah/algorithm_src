# A번 풀이 — 소방서 보수

## 문제 요약

N개 구역, M개 양방향 도로(가중치 w_i). 각 구역 i에 소방서가 있고, 소방차 출동까지 T_i분 소요.
구역 v의 진압 시간 = min over all u { T_u + dist(u, v) }.
전체 진압 시간 = 모든 구역 진압 시간의 최댓값.

K개 후보 중 하나를 골라 해당 소방서의 출동 시간을 floor(T_s / 2)로 줄일 수 있을 때,
전체 진압 시간의 최솟값과 최댓값을 구하라.

## 알고리즘

### 1단계: 다중 소스 Dijkstra (보수 전 상태)

모든 구역을 시작점으로 (u, T_u)를 힙에 넣고 한 번의 Dijkstra를 돌린다.

```
original[v] = min over all u { T_u + dist(u, v) }
```

이것이 보수 전 각 구역의 진압 시간.

### 2단계: 후보별 단일 소스 Dijkstra

각 후보 구역 s에 대해:
1. s에서 모든 구역으로의 최단거리 dist_s[v]를 구한다.
2. 보수 후 구역 v의 진압 시간 = min(original[v], floor(T_s/2) + dist_s[v])
3. 전체 진압 시간 = max over all v

K개 후보 전부에 대해 위를 계산하여 최솟값/최댓값을 출력.

### 정당성

보수로 바뀌는 것은 구역 s의 출동 시간뿐이다.
- 구역 v에 s가 아닌 소방서가 최적이었다면: original[v] 그대로
- 구역 v에 s가 최적이었다면: floor(T_s/2) + dist(s,v)로 더 좋아짐
- 어느 경우든 min(original[v], floor(T_s/2) + dist_s[v])가 정확한 새 진압 시간

## 핵심 아이디어

- 보수 전 상태를 다중 소스 Dijkstra **한 번**으로 전처리
- 보수 후 변화는 해당 구역 출발 경로에만 영향 → original과 min 취하면 충분
- 전체 진압 시간은 모든 구역 중 max → 보수로 병목 구역을 얼마나 줄이느냐가 관건

## 시간 복잡도

| 단계 | 복잡도 |
|------|--------|
| 다중 소스 Dijkstra | O((N+M) log N) |
| 후보별 Dijkstra × K | O(K × (N+M) log N) |
| **전체** | **O(K × (N+M) log N)** |

N=20,000, M=40,000, K=30 기준 약 2,800만 연산.
