# C번 풀이 — 지그재그 경로 (50점)

## 문제 요약

N개의 정점으로 이루어진 트리에서, 정점 번호가 번갈아 증가/감소하는 단순 경로(지그재그 경로) 중 
가장 긴 것의 정점 개수를 구하라.

지그재그 조건: a1 < a2 > a3 < a4 > ... 또는 a1 > a2 < a3 > a4 < ...

## 알고리즘

### Tree DP + Rerooting (전방위 트리 DP)

트리에서 경로는 유일하므로, 모든 경로는 "어떤 정점 v를 지나며 두 방향으로 뻗어나가는" 형태.
각 정점 v에서 인접 방향별 최장 지그재그 길이를 구한 뒤, v에서 두 방향을 결합하면 된다.

### 1단계: 서브트리 DP (Post-order)

루트를 0으로 잡고, 각 정점 v에 대해:

- `dp_up[v]`: v에서 서브트리 아래로, 첫 이동이 **증가**(v → child > v)인 최장 지그재그 길이
- `dp_dn[v]`: v에서 서브트리 아래로, 첫 이동이 **감소**(v → child < v)인 최장 지그재그 길이

자식 c에 대한 전이:
- c > v (증가): `dp_up[v] = max(dp_up[v], 1 + dp_dn[c])` — v→c 증가 후, c에서는 감소로 시작해야 지그재그 유지
- c < v (감소): `dp_dn[v] = max(dp_dn[v], 1 + dp_up[c])` — v→c 감소 후, c에서는 증가로 시작해야 지그재그 유지

각 방향별 top-2 값(어떤 자식이 기여했는지 포함)을 저장한다.

### 2단계: Rerooting (Pre-order)

경로는 서브트리를 벗어나 부모 방향으로도 뻗을 수 있다.
부모 p → 자식 c 방향으로 내려오면서, c에서 부모 방향으로의 기여를 계산:

- p > c (c→p 증가): `from_parent_up[c] = 1 + (p에서 c를 제외한 best_dn)`
- p < c (c→p 감소): `from_parent_dn[c] = 1 + (p에서 c를 제외한 best_up)`

"c를 제외한" 최대값은 top-2 기법으로 O(1)에 구한다:
- top-1이 c에서 나왔으면 top-2를 사용
- 아니면 top-1을 사용

부모 방향 기여도 추가하여 전방향 값 산출:
- `full_up[v] = max(dp_up[v], from_parent_up[v])`
- `full_dn[v] = max(dp_dn[v], from_parent_dn[v])`

### 3단계: 경로 결합

각 정점 v에서 답 후보:
1. **단일 방향**: `max(full_up[v], full_dn[v])`
2. **두 방향 결합** (v가 극소/극대점):
   - v가 극소점(valley): 증가 방향 top-2의 합 - 1 (v 중복 제거)
   - v가 극대점(peak): 감소 방향 top-2의 합 - 1

## 핵심 아이디어

- **Rerooting**: 서브트리 DP만으로는 부모 방향 경로를 놓침. 전방위 DP로 모든 방향 커버
- **Top-2 기법**: "특정 자식을 제외한 최대값"을 O(1)에 구하기 위해 각 방향별 상위 2개 값 저장
- **경로 결합**: 지그재그 경로가 한 정점을 지나 양쪽으로 뻗는 경우를 처리

## 시간 복잡도

| 단계 | 복잡도 |
|------|--------|
| BFS (부모/순서 구축) | O(N) |
| Post-order DP | O(N) |
| Top-2 정렬 | O(N) (각 노드에서 자식 수 합 = N-1) |
| Pre-order Rerooting | O(N) |
| **전체** | **O(N)** |

N = 200,000 기준 Python에서 약 1.3초. 2초 제한 내 충분.
