# C번 풀이 — 지그재그 경로 (50점)

## 난이도: Platinum IV

## 문제 요약

N개의 정점으로 이루어진 트리에서, 정점 번호가 번갈아 증가/감소하는 단순 경로(지그재그 경로) 중 
가장 긴 것의 정점 개수를 구하라.

지그재그 조건: a1 < a2 > a3 < a4 > ... 또는 a1 > a2 < a3 > a4 < ...

## 알고리즘

### Tree DP (서브트리 DP)

루트를 0으로 잡고 BFS로 순서를 구한 뒤, post-order로 각 정점에서의 최장 지그재그 길이를 계산한다.

### DP 정의

각 정점 v에 대해:

- `dp_up[v]`: v에서 서브트리 아래로, 첫 이동이 **증가**(v → child > v)인 최장 지그재그 길이
- `dp_dn[v]`: v에서 서브트리 아래로, 첫 이동이 **감소**(v → child < v)인 최장 지그재그 길이

자식 c에 대한 전이:
- c > v (증가): `dp_up[v] = max(dp_up[v], 1 + dp_dn[c])` — v→c 증가 후, c에서는 감소로 시작해야 지그재그 유지
- c < v (감소): `dp_dn[v] = max(dp_dn[v], 1 + dp_up[c])` — v→c 감소 후, c에서는 증가로 시작해야 지그재그 유지

### 답 산출

모든 정점에서 `max(dp_up[v], dp_dn[v])`의 최대값이 답.

## 핵심 아이디어

- 지그재그 조건에서 증가/감소가 번갈아야 하므로, 자식으로의 이동 방향과 반대 방향의 DP값을 이어붙인다
- 트리의 경로는 유일하므로 서브트리 내 경로만 고려하면 된다

## 한계

- 부모 방향으로 뻗는 경로를 고려하지 않음 (rerooting 미적용)
- 한 정점에서 두 방향으로 뻗는 경로 결합을 하지 않음

## 시간 복잡도

| 단계 | 복잡도 |
|------|--------|
| BFS (부모/순서 구축) | O(N) |
| Post-order DP | O(N) |
| **전체** | **O(N)** |
