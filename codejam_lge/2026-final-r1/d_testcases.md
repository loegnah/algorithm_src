# D번 테스트 케이스

## 문제 요약
N개의 사탕에서 연속 구간을 골라, 가장 맛있는 사탕 하나를 양보하고 나머지 합을 최대화하라.
답 = max over [L,R] of (sum(A[L..R]) - max(A[L..R]))

---

## TC 1: 예제 1 (문제 제공)
```
입력:
5
3 -2 5 1 -3

정답: 2
```
**설명:** [1,4] 구간 = {3, -2, 5, 1}. max=5 양보. 나머지 합 = 3+(-2)+1 = 2.

---

## TC 2: 예제 2 (문제 제공)
```
입력:
4
2 -1 -1 2

정답: 0
```
**설명:** 어떤 구간을 잡아도 양보 후 합이 0 이하.
[0,3] = 2+(-1)+(-1)+2 - 2 = 0. 길이 1 구간이면 합=0.

---

## TC 3: 최소 케이스 (N=2)
```
입력:
2
1 2

정답: 1
```
**설명:** 유일한 의미있는 구간 [0,1]. max=2 양보, 남은 합=1.

---

## TC 4: 전부 양수
```
입력:
5
1 2 3 4 5

정답: 10
```
**설명:** 전체 구간 [0,4]. 합=15, max=5 양보. 15-5=10.

---

## TC 5: 전부 음수
```
입력:
3
-5 -3 -1

정답: 0
```
**설명:** 어떤 구간을 잡아도 합-max < 0. 길이 1 구간으로 0을 얻는 게 최선.
[2,2] = 0 (max=-1 양보, 남은 사탕 없음).

---

## TC 6: 큰 양수 사이에 음수
```
입력:
5
10 -1 10 -1 10

정답: 18
```
**설명:** 전체 구간 합=28, max=10 양보, 28-10=18.

---

## TC 7: 하나의 큰 음수
```
입력:
5
5 5 -100 5 5

정답: 5
```
**설명:** [0,1] 구간: 합=10, max=5, 답=5. [3,4]도 동일.
전체 구간이면 합=-80, max=5, 답=-85 (나쁨).

---

## TC 8: 동일한 값
```
입력:
4
3 3 3 3

정답: 9
```
**설명:** 전체 구간 합=12, max=3 양보, 12-3=9.

---

## TC 9: 큰 양수 하나 + 나머지 양수
```
입력:
5
1 1 100 1 1

정답: 4
```
**설명:** 전체 구간 합=104, max=100, 답=4.
[0,1] 구간: max=1, 답=1. 전체가 더 좋다.

---

## TC 10: 음수 끝에 양수
```
입력:
6
-10 -10 5 3 -10 -10

정답: 3
```
**설명:** [2,3] 구간: 합=8, max=5, 답=3.
