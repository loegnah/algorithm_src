# C번 테스트 케이스

## 문제 요약
N개 정점 트리에서, 정점 번호가 번갈아 증가/감소하는 단순 경로(지그재그)의 최대 길이(정점 수)를 구하라.

---

## TC 1: 예제 (문제 제공)
```
입력:
5
0 2
2 1
2 3
1 4

정답: 4
```
**설명:** 트리 구조: 0-2, 2-1, 2-3, 1-4.
경로 [0, 2, 1, 4]: 0<2>1<4 → 증가, 감소, 증가 = 지그재그 4.
다른 후보: [3, 2, 1, 4] = 3>2>1 (감소 연속) → 불가.

---

## TC 2: 최소 케이스 (N=2)
```
입력:
2
0 1

정답: 2
```
**설명:** 간선 하나뿐. 경로 [0, 1] = 길이 2.
두 정점 경로는 항상 지그재그 조건을 만족한다 (비교할 연속 방향이 없음).

---

## TC 3: 단조 증가 체인 (지그재그 불가)
```
입력:
3
0 1
1 2

정답: 2
```
**설명:** 체인 0-1-2. 유일한 경로 0<1<2는 증가가 연속 → 지그재그 아님.
최장 지그재그 = 인접 2개 ([0,1] 또는 [1,2]).

---

## TC 4: 3정점 완벽 지그재그
```
입력:
3
0 2
2 1

정답: 3
```
**설명:** 체인 0-2-1. 경로 [0, 2, 1]: 0<2>1 → 완벽한 지그재그, 전체 3개.
또는 [1, 2, 0]: 1<2>0도 동일.

---

## TC 5: 스타 그래프 (중심=3)
```
입력:
6
3 0
3 1
3 2
3 4
3 5

정답: 3
```
**설명:** 중심 3, 잎 {0,1,2,4,5}. 스타에서는 모든 경로가 중심을 경유.
경로 길이 3: 예) [0, 3, 4] = 0<3>... 아 아닌데, 3<4이므로 0<3<4 = 증가 연속.
[4, 3, 2] = 4>3>2 = 감소 연속 → 불가.
[2, 3, 4] = 2<3<4 = 불가.
[0, 3, 4] = 0<3<4 = 불가.
[4, 3, 0] = 4>3>0 = 불가.
[0, 3, 5] = 0<3<5 = 불가.
[5, 3, 0] = 5>3>0 = 불가.
[4, 3, 2] = 4>3>2 = 불가.
[2, 3, 4] = 2<3<4 = 불가.

잠깐, 3보다 작은 잎(0,1,2)과 큰 잎(4,5)을 결합:
[4, 3, 2] = 4>3>2 → 감소 연속 = 불가.
그런데 정답이 3이면... [0, 3, 4]에서 0<3은 증가, 3<4도 증가 = 불가. 
아, 하지만 답이 3인 이유: 두 정점 경로가 2이고, 스타에서 3개짜리 지그재그가 있으려면 중심의 양쪽에 하나는 작고 하나는 큰 잎이 있어야 합니다.
여기서 [2, 3, ?]: 2<3은 증가, 다음은 감소 필요 → 3보다 작은 잎으로 가야함.
하지만 3에서 다음 잎으로 가면 이미 방문한 2 제외, 0 또는 1로 갈 수 있음.
[2, 3, 0] = 2<3>0 → 지그재그! 길이 3.
마찬가지로 [4, 3, 5] = 4>3<5 → 지그재그! 길이 3.

4개짜리: [0, 3, 4, ?] = 0<3... 3<4 증가 연속 → 불가.
스타에서 최대 3.

---

## TC 6: 완벽한 지그재그 체인 (전체 경로)
```
입력:
6
0 5
5 1
1 4
4 2
2 3

정답: 6
```
**설명:** 체인 0-5-1-4-2-3.
경로 [0, 5, 1, 4, 2, 3]: 0<5>1<4>2<3 → 완벽한 지그재그, N개 전부 사용.
정점 번호 배치가 이상적이면 전체 경로가 지그재그가 된다.

---

## TC 7: 긴 단조 체인 (최악)
```
입력:
4
0 1
1 2
2 3

정답: 2
```
**설명:** 체인 0-1-2-3. 모든 경로가 단조 증가(또는 감소).
어떤 부분 경로를 잡아도 연속 증가/감소 → 최대 길이 2.

---

## TC 8: 이진 트리
```
입력:
6
3 1
3 5
1 0
1 2
5 4

정답: 3
```
**설명:** 
```
       3
      / \
     1   5
    / \   \
   0   2   4
```
후보 경로:
- [2, 1, 3] = 2>1<3 → 길이 3
- [0, 1, 3] = 0<1<3 → 증가 연속, 불가
- [4, 5, 3] = 4<5>3 → 길이 3
- [0, 1, 2] = 0<1<2 → 불가

4개 이상: [2, 1, 3, 5] = 2>1<3<5 → 3<5 증가 연속(1<3 증가, 3<5 증가) → 불가
최대 = 3.

---

## TC 9: 캐터필러 트리
```
입력:
7
0 2
2 4
4 6
0 1
2 3
4 5

정답: 3
```
**설명:**
```
 1   3   5
 |   |   |
 0 - 2 - 4 - 6
```
척추(0-2-4-6)가 단조 증가라 긴 지그재그 불가.
- [1, 0, 2] = 1>0<2 → 길이 3
- [3, 2, 4] = 3>2<4 → 길이 3
- [5, 4, 6] = 5>4<6 → 길이 3
- [1, 0, 2, 3] = 1>0<2<3 → 2<3 연속 증가, 불가

최대 = 3. 척추의 단조성이 긴 지그재그를 차단한다.

---

## TC 10: 서브트리를 벗어나는 경로 (rerooting 필요)
```
입력:
5
0 3
3 1
1 4
4 2

정답: 5
```
**설명:** 체인 0-3-1-4-2.
경로 [0, 3, 1, 4, 2]: 0<3>1<4>2 → 완벽한 지그재그.
루트를 0으로 잡으면 2는 깊은 리프이고, 경로가 부모 방향으로 올라가야 하므로 rerooting 없이는 놓칠 수 있다.
