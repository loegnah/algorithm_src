# B번 풀이 — 케이블카 네트워크

## 문제 요약

백두산맥의 N개 봉우리가 일렬로 있고, i번 봉우리의 해발고도는 A_i.
봉우리 i와 j (i < j) 사이에 케이블카를 놓으려면 j - i >= K 이어야 한다.
노선 건설 비용 = max(A_i, A_{i+1}, ..., A_j) (구간 내 최대 해발고도).
모든 봉우리를 연결하는 최소 총 건설 비용을 구하라. 불가능하면 -1.

## 알고리즘

### 불가능 판정

N < 2K이면 거리 K 이상인 봉우리 쌍이 충분하지 않아 네트워크 구성 불가 → -1.

### Sparse Table (구간 최대 해발고도 쿼리)

O(N log N) 전처리, O(1) 쿼리.
케이블카 노선 비용 max(A_i, ..., A_j)를 빠르게 계산하는 데 사용.

### 간선 후보 축소 (핵심)

가능한 노선은 O(N²)개이지만, **거리 K과 K+1인 노선만으로 MST 구성 가능**.

- 거리 K 노선: (i, i+K) → N-K개
- 거리 K+1 노선: (i, i+K+1) → N-K-1개

**이유:**
1. 두 봉우리 사이 거리가 멀수록 구간이 넓어져 비용(구간 최대 해발고도)이 단조증가
   → 같은 두 봉우리를 잇더라도 최소 거리 노선이 항상 같거나 저렴
2. 거리 K 노선만으로는 봉우리가 K개 그룹으로 분리될 수 있음
   (예: K=2이면 짝수번/홀수번 봉우리가 서로 연결 불가)
3. GCD(K, K+1) = 1이므로 거리 K+1 노선을 추가하면 모든 그룹 연결 가능

### Kruskal MST

약 2N개 노선을 건설 비용 기준 오름차순 정렬 후 Union-Find로 MST 구성.

## 핵심 아이디어

- 구간 최댓값의 단조성을 이용해 O(N²) → O(N) 후보 노선으로 축소
- GCD(K, K+1) = 1 성질로 전체 연결성 보장
- Sparse Table로 노선 비용을 O(1)에 계산

## 시간 복잡도

| 단계 | 복잡도 |
|------|--------|
| Sparse Table 전처리 | O(N log N) |
| 노선 생성 | O(N) |
| 정렬 | O(N log N) |
| Kruskal (Union-Find) | O(N α(N)) ≈ O(N) |
| **전체** | **O(N log N)** |

N = 100,000 기준 총 연산 약 570만 회. Python에서도 2초 제한 내 충분.
