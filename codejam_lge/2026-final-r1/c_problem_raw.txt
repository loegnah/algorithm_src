C번 - 지그재그 경로 50점
시간 제한	메모리 제한
2 초 (추가 시간 없음)	1024 MB (추가 메모리 없음)
문제
트리 위에서 지그재그 경로란 다음 조건을 모두 만족하는 단순 경로를 의미한다.

경로가 정점 수열
$$(a_1, a_2, \dots, a_k)$$
으로 표현될 때, 모든 
$1 \le i < k$에 대해 
$(a_i, a_{i+1})$가 트리의 간선이다.
모든 정점은 서로 달라야 한다. 즉, 
$a_1, a_2, \dots, a_k$가 모두 서로 다른 정점이다.

또한, 정점 번호의 크기가 번갈아 증가, 감소해야 한다. 즉,
또는
$$a_1 < a_2 > a_3 < a_4 > \dots \quad \text{또는} \quad a_1 > a_2 < a_3 > a_4 < \dots$$ 
위 조건을 만족하는 경로 중 가장 긴 것의 길이(정점 개수)를 구하시오.
 

입력
첫째 줄에 정점의 개수 
$N$이 주어진다. 
$(2 \le N \le 200\,000)$ 

다음 
$N-1$개의 줄에는 간선의 정보가 주어진다. 각 줄마다 두 정수 
$u$, 
$v$가 공백으로 구분되어 주어지며, 이는 정점 
$u$와 정점 
$v$가 간선으로 연결되어 있음을 의미한다.

출력
가장 긴 지그재그 경로의 길이를 출력한다.

제한
 
$2 \le N \le 200{,}000$ 
 
$0 \le u,v \le N-1$ 
입력으로 주어진 그래프는 트리다.
예제 입력 1 
5
0 2
2 1
2 3
1 4
예제 출력 1 
4
[0, 2, 1, 4]이 가장 긴 지그재그 경로이다.
